# M001: 创建初始化文件与基础架构

> **所属阶段**：第一阶段 - 基础架构
> **预计周期**：第 1 周
> **优先级**：P0
> **前置任务**：无

## 一、任务目标
搭建 Spring Boot 3.x + Java 17 的 Maven 多模块项目骨架，建立 `intellimes-common`、`intellimes-system`、`intellimes-mes`、`intellimes-wms`、`intellimes-ai` 五大子模块，并完成父 pom 依赖统一管理、`application.yml` 基础配置占位符与标准分层目录结构，为后续所有业务模块开发奠定工程基础。

## 二、前置条件
- 本机已安装 JDK 17、Maven 3.8+、IDEA（或 VSCode）
- 本机已安装 MySQL 8.0、Redis、RabbitMQ、Elasticsearch（或可用 Docker 拉起）
- 已阅读 `IntelliMES.md` 总体架构与模块划分

## 三、详细执行步骤
### 步骤 1：创建父工程目录
在 `e:\Project\IntelliMES\` 下创建父工程目录 `intellimes-backend`，进入该目录。

### 步骤 2：编写父 pom.xml
在 `intellimes-backend/pom.xml` 中：
- groupId 设为 `com.intellimes`，artifactId 设为 `intellimes-parent`，version `1.0.0`
- packaging 设为 `pom`
- 在 `<properties>` 中统一定义版本号：`java.version=17`、`spring-boot.version=3.2.x`、`mybatis-plus.version=3.5.5`、`redisson.version=3.25.x`、`hutool.version=5.8.x`、`jjwt.version=0.12.x`、`spring-ai.version=1.0.0-M1`
- 使用 `<dependencyManagement>` 引入 `spring-boot-dependencies`、`spring-ai-bom`
- 在 `<modules>` 中声明 5 个子模块

### 步骤 3：创建 common 子模块
创建目录 `intellimes-common`，pom 中 packaging 为 `jar`。该模块存放公共工具、统一返回结果、异常、 BaseEntity 等，被其他模块依赖。

### 步骤 4：创建 system 子模块
创建目录 `intellimes-system`，依赖 `intellimes-common`。用于用户、角色、权限、登录鉴权。

### 步骤 5：创建 mes / wms / ai 子模块
分别创建 `intellimes-mes`、`intellimes-wms`、`intellimes-ai`，均依赖 `intellimes-common`。其中 `intellimes-ai` 额外引入 `spring-ai-openai-spring-boot-starter`。

### 步骤 6：创建启动模块
在 `intellimes-system`（或单独的 `intellimes-admin` 聚合模块）中创建启动类 `IntelliMesApplication`，标注 `@SpringBootApplication` 与 `@MapperScan("com.intellimes.**.mapper")`。

### 步骤 7：配置 application.yml
在启动模块 `src/main/resources/application.yml` 写入：
- `server.port: 8080`、`spring.application.name: intellimes`
- `spring.datasource`（MySQL 占位符 `jdbc:mysql://localhost:3306/intellimes?...`）
- `spring.data.redis`（host/port/password 占位）
- `spring.elasticsearch.uris` 占位
- `spring.rabbitmq`（host/port/username/password 占位）
- `mybatis-plus` 配置（mapper-locations、map-underscore-to-camel-case、logic-delete-field: deleted）
- 通过 `application-dev.yml`/`application-prod.yml` 区分环境，使用 `spring.profiles.active=dev`

### 步骤 8：建立标准分层目录
在每个业务子模块 `src/main/java/com/intellimes/{module}/` 下建立：
- `controller` 控制层
- `service` / `service.impl` 服务层
- `mapper` 数据访问层
- `entity` 实体类
- `dto` 入参对象
- `vo` 出参对象
- `config` 配置类

### 步骤 9：编写 .gitignore 与 README
根目录添加 `.gitignore`（忽略 target/、*.iml、.idea/、logs/、application-local.yml）。在 `intellimes-backend` 下创建简短 README 说明模块划分。

### 步骤 10：本地编译验证
在 `intellimes-backend` 目录执行 `mvn clean install -DskipTests`，确认 5 个模块全部编译通过。

## 五、预期产出
- 一个可 `mvn clean install` 通过的 Maven 多模块工程
- 5 个子模块完整目录结构与 pom
- 一份带占位符的 `application.yml`（数据库/Redis/ES/MQ 连接）

## 六、验证方式
- 执行 `mvn clean install -DskipTests` 返回 BUILD SUCCESS
- `mvn dependency:tree` 能看到 Spring Boot 3.x 与各中间件 starter
- 在 IDEA 中可直接运行 `IntelliMesApplication` 启动类（端口 8080）
- 目录结构中各模块分层齐全

## 七、技术要点与注意事项
- **版本对齐**：Spring Boot 3.x 强制要求 Java 17+，编译插件 `maven-compiler-plugin` 的 `release` 必须设为 17，否则报 `unsupported class file version`。
- **多模块依赖**：子模块依赖父 pom 中 `<dependencyManagement>` 管理的版本时，可省略 `<version>`，便于统一升级。
- **AI 模块独立**：`spring-ai-bom` 版本与 Spring Boot 版本需匹配，建议参考 Spring AI 官方兼容矩阵。
- **配置占位符**：`application.yml` 中所有中间件连接信息用占位符 + `${ENV_VAR:default}` 形式，避免硬编码敏感信息。
- **MapperScan 范围**：使用 `com.intellimes.**.mapper` 通配，确保所有子模块 Mapper 都能被扫描到。
- **环境隔离**：通过 `spring.profiles.active` 切换 dev/prod，敏感配置通过环境变量注入。
