# M006: Vue3前端项目初始化

> **所属阶段**：第一阶段 - 基础架构
> **预计周期**：第 2 周
> **优先级**：P0
> **前置任务**：M004

## 一、任务目标
使用 Vite 创建 Vue 3 + TypeScript 前端工程，集成 Element Plus、Pinia、Vue Router、Axios 封装（请求/响应拦截、自动携带 Token），完成整体布局（侧边栏菜单、头部、内容区）与登录页对接后端 `/auth/login` 接口，建立前端工程基座。

## 二、前置条件
- M004 已完成，后端登录接口可用，admin/123456 账号已存在
- 本机已安装 Node.js 18+、pnpm（或 npm）

## 三、详细执行步骤
### 步骤 1：创建前端工程
在 `e:\Project\IntelliMES\` 下执行：
```
npm create vite@latest intellimes-frontend -- --template vue-ts
cd intellimes-frontend
npm install
```

### 步骤 2：安装核心依赖
```
npm install element-plus @element-plus/icons-vue
npm install pinia pinia-plugin-persistedstate
npm install vue-router@4
npm install axios
npm install nprogress @types/nprogress
npm install -D unplugin-auto-import unplugin-vue-components sass
```

### 步骤 3：配置 vite.config.ts
- 配置 `@` 别名指向 `src`
- 配置代理 `/api` 转发到 `http://localhost:8080`（解决跨域）
- 集成 `unplugin-auto-import` 与 `unplugin-vue-components` 自动按需引入 Element Plus
- `server.port: 5173`

### 步骤 4：配置 Element Plus
在 `src/main.ts`：
- `app.use(ElementPlus)` 全量引入 或 配置按需引入
- 注册所有 `@element-plus/icons-vue` 图标为全局组件
- 引入 Element Plus 中文 locale

### 步骤 5：封装 Axios request.ts
在 `src/utils/request.ts`：
- `baseURL: '/api'`
- 请求拦截器：从 pinia user store 取 token，加到 Header `Authorization: Bearer xxx`
- 响应拦截器：
  - HTTP 200 且 `res.code===200` 返回 `res.data`
  - `res.code===401` 跳转登录页并清空 token
  - 其他错误 `ElMessage.error(res.message)`
  - HTTP 404/500 统一提示
- 超时 10s，loading 可配置

### 步骤 6：配置 Pinia 状态管理
在 `src/stores/`：
- `user.ts`：token、userInfo、permissions，`login`/`logout`/`getInfo` actions，用 `persist` 持久化 token
- `app.ts`：侧边栏折叠状态、主题
- 在 `main.ts` 注册 pinia 与 persist 插件

### 步骤 7：配置 Vue Router
在 `src/router/index.ts`：
- 路由表：`/login`、`/`（布局含 children）、`/404`
- 动态路由：登录后从 `/auth/info` 获取菜单，`addRoute` 注入
- 全局前置守卫 `beforeEach`：未登录跳 `/login`，白名单放行登录页
- NProgress 进度条

### 步骤 8：编写整体布局 Layout
在 `src/layout/`：
- `index.vue`：`el-container` 包含 Header、Aside、Main
- `components/Sidebar.vue`：递归菜单组件，根据权限渲染
- `components/Navbar.vue`：面包屑、用户头像下拉（个人信息/退出登录）
- `components/AppMain.vue`：`<router-view>` + keep-alive

### 步骤 9：编写登录页
在 `src/views/login/index.vue`：
- `el-form` 用户名密码输入框 + 登录按钮
- 调用 `userStore.login(loginForm)`，成功后跳 `/`
- 表单校验（必填、长度）
- 美化样式（背景、卡片）

### 步骤 10：编写 Dashboard 首页
- 简单的欢迎页 + 几个统计卡片占位（待后续 M018 看板填充）
- 验证登录后能正常进入

### 步骤 11：联调验证
- 启动后端 `mvn spring-boot:run` 与前端 `npm run dev`
- 浏览器访问 http://localhost:5173/login
- 输入 admin/123456 登录，跳转首页
- 刷新页面 token 仍在（持久化生效）
- 退出登录回到登录页

## 七、技术要点与注意事项
- **Vite 代理**：开发期用 `server.proxy` 转发 `/api` 到后端 8080，避免 CORS；生产期由 Nginx 反向代理处理。
- **Axios 拦截器**：请求拦截加 Token，响应拦截统一处理 401（跳登录）、业务错误码（弹 message），业务代码只关心 `res.data`，简化调用。
- **Pinia 持久化**：`pinia-plugin-persistedstate` 默认存 localStorage，token 持久化避免刷新掉线；敏感信息建议存 sessionStorage 或 cookie。
- **动态路由**：登录后从 `/auth/info` 拿菜单转成路由 `addRoute`，避免硬编码路由表，符合 RBAC 控制。
- **路由守卫**：白名单放行登录页，其他页面无 token 跳登录并记录 `redirect` 参数，登录后跳回原页面。
- **Element Plus 按需引入**：`unplugin-auto-import` + `unplugin-vue-components` 自动按需引入组件与 API，减小打包体积。
- **TypeScript 严格模式**：`tsconfig.json` 开启 `strict: true`，类型错误在编译期暴露，避免运行时 undefined。
