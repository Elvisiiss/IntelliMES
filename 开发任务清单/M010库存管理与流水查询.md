# M010: 库存管理与流水查询

> **所属阶段**：第二阶段 - WMS 仓储模块
> **预计周期**：第 4 周
> **优先级**：P0
> **前置任务**：M009

## 一、任务目标
实现实时库存查询（按物料/仓库/货位筛选，显示 quantity、locked_quantity、可用库存）与库存流水查询（inventory_log 列表），并提供库存看板概览（总物料数、总库存价值、低库存预警），为仓储管理提供数据可视化能力。

## 二、前置条件
- M009 已完成，inventory 与 inventory_log 表有数据
- M003 分页插件可用

## 三、详细执行步骤
### 步骤 1：编写库存查询后端
`InventoryController`：
- `POST /wms/inventory/page` 分页查询：支持按 materialId、warehouseId、locationId、materialName 筛选
- 返回 `InventoryVO`（物料编码、名称、仓库、货位、quantity、locked_quantity、available、单位）
- `GET /wms/inventory/listByMaterial/{materialId}` 按物料汇总各货位库存

### 步骤 2：编写库存 Mapper XML
`InventoryMapper.xml`：
- 联表查询 inventory + material + warehouse + storage_location
- 计算 `available = quantity - locked_quantity`
- 支持多条件动态 WHERE

### 步骤 3：编写库存流水查询后端
`InventoryLogController`：
- `POST /wms/inventory/log/page` 分页查询
- 筛选条件：materialId、changeType、sourceType、时间范围
- 返回 `InventoryLogVO`（物料信息、变动类型、变动数量、前后数量、来源、操作人、时间）

### 步骤 4：编写库存看板接口
`InventoryDashboardController`：
- `GET /wms/inventory/dashboard/overview`：
  - totalMaterialCount 物料总数
  - totalQuantity 库存总量
  - totalValue 库存价值（需 material 表加 unit_price 字段或单独维护）
  - lowStockList 低库存预警（available < 阈值）
  - inboundOutboundStat 本周入出库统计

### 步骤 5：编写前端 API
- `src/api/wms/inventory.ts`：库存查询、看板
- `src/api/wms/inventoryLog.ts`：流水查询

### 步骤 6：编写库存查询前端页面
`src/views/wms/inventory/index.vue`：
- 顶部筛选区（物料名称、仓库、货位、状态）
- `el-table` 列表：物料编码、名称、仓库、货位、库存、锁定、可用、单位
- 可用库存列用颜色标识（红色低库存、绿色正常）
- `el-pagination` 分页
- 导出按钮（前端导出 Excel）

### 步骤 7：编写库存流水前端页面
`src/views/wms/inventory/log.vue`：
- 筛选区（物料、变动类型下拉、来源类型、时间范围 `el-date-picker`）
- `el-table`：时间、物料、变动类型（tag 颜色区分入库/出库/盘点）、变动数量、前→后、来源、操作人
- 分页

### 步骤 8：编写库存看板页面
`src/views/wms/dashboard/inventory.vue`：
- 顶部 4 个统计卡片（物料数、库存量、价值、低库存预警数）
- 中部 ECharts 图表：本周入出库柱状图
- 底部低库存预警表格

### 步骤 9：配置路由与菜单
添加菜单：
- `/wms/inventory` 库存查询
- `/wms/inventory-log` 库存流水
- `/wms/inventory-dashboard` 库存看板（或归到首页 Dashboard）

### 步骤 10：联调验证
- 入库 100、出库 30 后，库存查询显示 quantity=70、locked=0、available=70
- 审核一张出库单 20 后，locked=20、available=50
- 流水页面显示所有入出库记录
- 看板统计数字正确

## 五、预期产出
- 实时库存查询（多条件筛选 + 联表展示）
- 库存流水查询（按时间/类型/来源筛选）
- 库存看板（统计卡片 + 图表 + 低库存预警）
- 仓储管理人员日常使用的核心页面

## 六、验证方式
- 库存查询页面按物料名筛选正确返回
- available = quantity - locked_quantity 计算正确
- 流水页面按变动类型筛选只显示对应记录
- 时间范围筛选生效
- 看板统计数字与库存查询一致
- 低库存预警列表正确显示 available < 阈值的物料

## 七、技术要点与注意事项
- **available 计算一致性**：后端 SQL 计算 `quantity - locked_quantity` 与前端展示必须一致，避免一处算一处不算导致数据对不上。
- **联表查询性能**：inventory 联 material/warehouse/location 三表查询，数据量大时需在 material_id、warehouse_id、location_id 建索引，分页避免全表扫描。
- **流水时间索引**：inventory_log 按时间范围查询是高频场景，`idx_create_time` 索引必备。
- **看板统计优化**：总库存量、物料数等统计可用 `SELECT COUNT/SUM` 单独查询，避免拉全表到内存计算；高频看板可考虑 Redis 缓存（计划书 5.3 热点缓存场景）。
- **低库存阈值**：可在 material 表加 `safety_stock` 字段，available < safety_stock 触发预警。
- **变动类型 tag**：前端用 `el-tag` 颜色区分入库（绿）、出库（红）、盘点（黄），提升可读性。
- **导出 Excel**：大数据量导出用 EasyExcel 流式写入，避免 OOM。
