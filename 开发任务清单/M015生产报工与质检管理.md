# M015: 生产报工与质检管理

> **所属阶段**：第三阶段 - MES 生产模块
> **预计周期**：第 5 周
> **优先级**：P0
> **前置任务**：M014

## 一、任务目标
实现生产报工记录管理：工人提交报工（report_quantity 报工数量、qualified_quantity 合格数量、scrap_quantity 废品数量），质检合格/不合格处理，退料/废料操作，并在报工时联动更新工单 completed_quantity，前端提供报工界面。

## 二、前置条件
- M014 已完成，工单可派工为生产中状态
- M002 中 work_report 表已建好
- M013 工序数据可选

## 三、详细执行步骤
### 步骤 1：编写报工记录后端实体与 Mapper
在 `intellimes-mes`：
- `entity/WorkReport`（orderId、workerId、processId、reportQuantity、qualifiedQuantity、scrapQuantity、reportTime、remark、qualityStatus）extends BaseEntity
- `mapper/WorkReportMapper` + XML 联表查询（关联工单、用户、工序）

### 步骤 2：编写报工 Service
`WorkReportService`：
- `report(WorkReportDTO)`：
  - 校验工单状态为生产中
  - 校验 reportQuantity = qualifiedQuantity + scrapQuantity + 待返修数量
  - 保存报工记录，qualityStatus=0 待质检
  - 调用 `ProductionOrderService.updateCompletedQuantity(orderId, qualifiedQuantity)` 累加工单已完成数量（只算合格数）
- `qualityCheck(id, result)`：质检
  - result=合格：qualityStatus=1
  - result=不合格：qualityStatus=2，触发退料/废料流程
- `scrap(orderId, materialId, quantity)`：废料登记，调用 WMS 出库（source_type=SCRAP）
- `returnMaterial(orderId, materialId, quantity)`：退料，调用 WMS 出库（source_type=RETURN）
- `pageQuery` 按工单、工人、时间筛选

### 步骤 3：编写报工 Controller
`WorkReportController`：
- `POST /mes/report/page` 分页
- `POST /mes/report` 提交报工
- `PUT /mes/report/quality/{id}` 质检
- `POST /mes/report/scrap` 废料登记
- `POST /mes/report/return` 退料
- `GET /mes/report/listByOrder/{orderId}` 按工单查询报工记录

### 步骤 4：编写质检 Service
`QualityCheckService`：
- `pass(id)`：合格处理
- `fail(id, reason)`：不合格处理，记录原因
- `rework(id)`：返工处理，重新报工
- 质检统计数据：合格率、废品率

### 步骤 5：编写前端 API 与页面
- `src/api/mes/report.ts`
- `src/views/mes/report/index.vue`：报工记录列表（工单号、工人、工序、报工数量、合格、废品、质检状态、时间）
- `src/views/mes/report/form.vue`：报工表单
  - 选择工单（下拉只显示生产中工单）
  - 选择工序
  - 输入报工数量、合格数量、废品数量（自动校验合格+废品=报工）
  - 备注
- `src/views/mes/report/quality.vue`：质检界面（列表 + 合格/不合格按钮 + 不合格原因输入）

## 五、预期产出

## 六、验证方式
- 报工后 work_report 表有记录，工单 completedQuantity 增加
- reportQuantity = qualifiedQuantity + scrapQuantity 校验生效
- 质检合格/不合格状态正确更新
- 废料登记后 WMS 出库单生成（source_type=SCRAP）
- 退料后 WMS 出库单生成（source_type=RETURN）
- 工单 completedQuantity 达到 quantity 时可触发完工

## 七、技术要点与注意事项
- **报工数量校验**：reportQuantity = qualifiedQuantity + scrapQuantity + reworkQuantity（返修），三者之和等于报工总数，避免数据不一致。
- **completedQuantity 累加**：工单已完成数量只累加合格数量（qualifiedQuantity），废品不计入完工进度，符合生产实际。
- **质检解耦**：报工与质检分离，报工后进入待质检状态，质检员独立处理，避免报工工人自报自检。
- **废料退料联动 WMS**：废料登记与退料本质是 WMS 出库，复用 OutboundOrderService 创建出库单，source_type 标识来源（SCRAP/RETURN），实现 MES 与 WMS 数据贯通。
- **报工并发**：多工人同时报工同一工单，调用 `updateCompletedQuantity` 时复用工单乐观锁防并发覆盖。
- **质检统计**：合格率 = qualified / report * 100%，废品率 = scrap / report * 100%，用于生产看板（M018）展示。
